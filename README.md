# generador de alumnos

Creado por: Montaño Lares Leonardo

Este es una pagina web que hice como parte de la clase de Bases de Datos II con gran asistencia del Maestro Abril García.

Es una pagina que genera una cantidad especificada de alumnos con un nombre (o mas), apellido paterno o materno, un numero de matricula del estilo de la unison, y un correo de la unison.

Esta lista de alumnos se puede poner en tablas de 4 formatos, MySQL/MariaDB, PostgreSQL, CSV y JSON.

El segundo apellido esta en ruso por requerimientos dados por el maestro.
